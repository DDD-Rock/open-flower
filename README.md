# YzY - Auto Buff（Windows）

> Power by 小新

`open-flower` 是 YzY - Auto Buff 的 Windows / Python 版本，与 macOS
版 AutoBuff 保持相同的主要功能、配置语义和界面结构。

启动软件时使用 AutoBuff Monitor 账号登录；Windows、macOS 客户端和监控网页
共用同一套账号，不再使用机器码或离线激活码。

用户名仅用于登录，登录后的客户端界面和云端地图库只展示注册昵称。
本地及云端地图库都使用直接可见的列表选择地图，不使用下拉框。
云端地图支持上传当前选中的单张地图，也可批量上传全部地图。
登录时上报 Windows 客户端版本；被超级管理员禁用的版本会提示更新并拒绝登录。
窗口顶部常驻醒目显示当前客户端版本号，切换任何功能都可见。

客户端首次登录会登记一个保存在本机配置目录中的设备 ID。软件升级会沿用该 ID，
不会重复占用客户端名额；退出账号只清除登录令牌，不会改变本机设备身份。

## 主要功能

- 死花模式：BUFF 到期后离开自由市场、移动并释放 BUFF，随后返回市场。
- 活花模式：在当前地图循环释放 BUFF。
- 跟补模式：持续释放加血技能；BUFF 到期时优先补 BUFF，再继续补血。
- 监控模式：约 30 FPS 只读显示小地图、自己/队友/其他玩家位置、EXP、符文、鼠标跟随验证和安全区状态。
- 神殿模式 · 挂绳组队（第一阶段）：保存角色名、打开/复制客户端管理页；接收网页编队后自动切换模式、开启自动同意组队并运行。首次创建时由队长拟人输入建队和邀请指令，成员接受后实时上报进队状态。
- 挂绳队伍每个账号仅允许一个；网页解散后，在线队长客户端会拟人输入 `/退出隊伍`。
- 神殿模式 · 休息室：开始时立即释放一轮；黄点或橙点人数连续两帧确认增加、或自动接受组队成功时，再释放全部 BUFF，并切换队伍频道发送随机自然喊话。BUFF 倒计时结束不会触发释放。
- 神殿模式 · 进出自由：复用已验证的死花进出市场、移动、释放和返回流程，并保留神殿模式入口。
- 休息室防卡移动默认每隔随机 15–30 分钟短暂右走再左走，可配置 1–1440 分钟。
- EXP 使用固定锚点模板定位经验面板，再由 PP-OCRv4 读取整行；读数连续三帧一致后才发布。
- 多地图库：支持手工或黄点轨迹标注平台/绳索、传送点连接、Mac/Windows 地图导入导出。
- 路径工具：显示路径图、独立测试全部动作组合，并按实时黄点逐步重规划到平台或传送点。
- 登录后保持持久监控连接，网页可查看状态并远程开始或停止监控。
- 每个 BUFF 在最后一次按键成功按下时立即开始独立倒计时。
- 日志显示对应 BUFF 的倒计时和下次释放时间。
- 游戏窗口自动识别、自动恢复焦点。
- 小地图、玩家黄点、蓝色传送门及自由市场按钮检测。
- 手动标记传送门；标记前会确认角色当前处于市场。
- 空闲时坐椅子。
- 配置自动保存。

## 界面与默认设置

- 程序名称：`YzY - Auto Buff`
- 默认显示 3 个 BUFF 配置。
- 支持手动增加或删除 BUFF，最多 8 个。
- BUFF 1 默认：启用、按键 `1`、持续 `200` 秒。
- BUFF 2 默认：启用、按键 `2`、持续 `200` 秒。
- 死花模式默认“出市场后移动方式”为“只向右（骨龙、忘却）”。
- 活花模式提供“移动方式 / 提前释放 / 空闲时坐椅子”三列配置。
- 死花模式提供“出市场后移动方式 / 跳跃键 / 空闲时坐椅子”三列配置。
- 跟补模式提供“加血技能键 / 瞬移技能键 / 跟补基准点”配置。加血会持续按住 8–12 秒，每轮间隔 0.25–0.6 秒；每隔 4–7 秒向基准点瞬移一次。若角色距离基准点在允许范围的一半以内（例如 ±4 时处于 ±2 内），定时修正会先向外瞬移，短暂拟人间隔后立刻瞬移回来。系统会在界限的 75% 处提前保护；左侧达到提前保护线时会绕过间隔和反向保护，立即向右强制回位。越界回位后高频采样黄点，一旦发现左侧危险落点就立即结束等待并再次回位；右侧仍保留反向防抖，同时不会重置独立的定时瞬移。标记基准点时可设置左右界限，界限会直接显示在小地图上。
- 运行日志默认折叠显示最后一条记录，可手动展开。
- 主窗口固定为 `520×620`，不允许拉伸；内容超出时使用内部滚动。

Windows 配置保存在：

```text
%APPDATA%\YzY-Auto-Buff\settings.ini
```

首次启动新版时，如果程序目录存在旧 `settings.ini`，会自动读取旧配置；
后续保存到用户配置目录。旧版六个全空槽位会自动折叠为三个，实际配置过的
附加槽位会保留。

## 环境要求

- Windows 10 / 11
- Python 3.10+
- 建议使用管理员权限运行

安装依赖：

```bash
pip install -r requirements.txt
```

启动：

```bash
python main.py
```

也可以使用：

```text
start_admin.bat
```

## 使用流程

1. 启动游戏和 YzY - Auto Buff。
2. 确认顶部“管理员”和“游戏窗口”状态。
3. 选择死花模式、活花模式、跟补模式、监控模式或神殿模式。
4. 配置 BUFF 按键、持续时间和模式选项。
5. 点击底部“开始运行”。

运行过程中点击脚本窗口导致游戏失去焦点时，程序会停止当前方向状态、
恢复游戏窗口焦点，再继续移动或释放技能。只有焦点正常时才会把角色不动
判定为移动停滞。

## 死花模式移动方式

- `先右再左`
- `只向左（鱼窝）`
- `只向右（骨龙、忘却）`（新安装默认）

## 传送门标记

只有检测到当前处于自由市场时，才允许进入传送门截图标记界面。

- 蓝色标记：自动检测位置。
- 红色标记：手动选择位置。
- 手动坐标会跟随设置持久化保存。

## 跟补模式

跟补模式运行前需要先设置“加血技能键”，再点击“标记”在小地图上选择跟补基准点。确认时会同时保存小地图区域；运行后只使用该点的 X 坐标作为基准，纵向坐标不参与判断。

- 基准 X 左右 `6` 个小地图点都算在区域内。
- 每隔随机 `12-15` 秒向基准 X 中心小走一段；如果已经在中心附近，则向右小走一步，默认按住方向键 `200-300ms`，可在界面调整。
- 如果黄点被碰撞或手动走出区域，会持续按住方向键回到区域内，到位后立刻松开。
- 加血技能会在急促连按、短按住、长按住之间随机切换，长按占比更高。
- BUFF 到期时会暂停补血，按两次释放 BUFF，多个 BUFF 之间使用较短随机间隔，然后继续补血。

## 测试

```bash
PYTHONPYCACHEPREFIX=/tmp/open-flower-pycache \
python3 -m unittest discover -s tests -v

PYTHONPYCACHEPREFIX=/tmp/open-flower-pycache \
python3 -m compileall -q .
```

Windows 上还需要进行以下人工测试：

- 三种模式的真实按键释放。
- 移动中点击脚本窗口后的焦点恢复。
- 市场识别、小地图导航和传送门进入。
- 跟补基准点标记、启动后立即 Buff/补血、被撞后回到 `X ± 6` 区域。
- 监控模式地图匹配、EXP/符文/鼠标跟随验证识别、安全区状态、紧急通知和网页远程启停。
- 地图自动采集、每种动作组合及同图/跨地图路径执行；动作测试必须由人工逐项确认。
- 打包后的管理员权限、图标和模板资源加载。
